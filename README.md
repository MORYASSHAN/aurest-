# Aurest Biotech  Sealing Lives. Healing Futures.™

Aurest Biotech is a modern web project built around the identity and digital presence of a biotechnology brand.

🌐 **Live Website:** https://aurest.vercel.app/

## Overview

Aurest is designed to establish a professional digital presence for a biotech brand, communicating its identity through a clean, modern web experience.

The website serves as the primary online destination for visitors to explore the brand and learn more about its mission.

## Features

* **Brand Identity:** A distinctive digital presence for Aurest Biotech.
* **Modern UI/UX:** A contemporary interface designed to present the brand professionally.
* **Responsive Design:** Intended to provide a consistent browsing experience across devices.
* **Web Deployment:** Hosted on Vercel for public access.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

* Node.js and npm, if the project uses a Node.js-based frontend.
* Git.
* A local copy of the project repository.

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <YOUR_PROJECT_DIRECTORY>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server using the script configured in `package.json`:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, commonly `http://localhost:3000` or `http://localhost:5173`, depending on your framework.
